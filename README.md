# Homebrew tap for Zume Editor

```bash
brew tap zume-editor-dev/zume
brew install --cask zume-editor
```

**Zume Editor** is a fast, native text, code and hex editor for Windows, macOS and Linux.
This tap provides the macOS (Apple Silicon) cask.

- Download (all platforms): https://smolt-stage.com/home/en/download.html
- Website: https://smolt-stage.com/home/en/zume-editor.html
- Releases: https://github.com/zume-editor-dev/zume-editor-releases/releases
- Feedback: https://github.com/zume-editor-dev/zume-editor-help/issues

> Free public beta — all features are free to use until 2027-03-31.
